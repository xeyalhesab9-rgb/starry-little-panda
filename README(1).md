# Starry Little Panda — Make the Cutest Picture

An offline, deterministic Python 3.13 entry for the make.fun “Make the cutest picture” bounty.

## Files
- `main.py` — copies the bundled picture to `/output/entry.png`.
- `entry.png` — 1024×1024 PNG artwork (under 1 MiB).
- `LICENSE` — MIT License.

## Run
```sh
python main.py
```

The program uses only Python's standard library and performs no network access. It copies the same bundled image bytes on every run.
